# Archive

`old-site/` is a snapshot of the previous translationCore website (the Netlify version, repository `unfoldingWord/tc-website` before the refresh). It is kept here as a record only.

- It is **not deployed**. Cloudflare Pages publishes only the `site/` folder.
- Do not edit it. If something from it is needed again, copy it into `site/`.
- Its `tc-help/` folder (the translationCore Desktop help pages) is the one part that is still live: a copy sits in `site/tc-help/` because the new site links to it.
- Its `translationcore/`, `translation-helps/` and `tc4/` pages are replaced by the new Desktop and Biblical Resources pages; the old addresses redirect through `site/_redirects`.
